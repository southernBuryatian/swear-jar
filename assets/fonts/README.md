# Fonts

The app uses **Pixelify Sans** via the variable font:

- `PixelifySans-VariableFont_wght.ttf` (weights 400–700)

Loaded in `src/fonts/pixelify-sans.css`. The static `.ttf` files in this folder are optional extras from the same family.

[Pixelify Sans on Google Fonts](https://fonts.google.com/specimen/Pixelify+Sans) — SIL Open Font License.
